# 돌 다마고치 뽀모도로

집중용 Flowtime 타이머 + 돌 육성 웹게임. 서버 없는 리액트 SPA. 내가 쓰려고 만듬.

**▶ 플레이: https://dasom2334.github.io/dolmagochi/**

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 프로덕션 빌드
```
