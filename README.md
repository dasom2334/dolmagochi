# 돌 다마고치 뽀모도로

집중용 Flowtime 타이머 + 돌 육성 웹게임. 서버 없는 리액트 SPA. 내가 쓰려고 만듬.

**▶ 플레이: https://dolmagochi.dacotton.dev**

## 어떤 게임인가

공부하는 동안 돌이 옆에 있다. 타이머는 카운트다운이 아니라 **카운트업**이고 (Flowtime),
끊고 싶을 때 끊으면 된다. 집중한 시간만큼 휴식이 배정되고, 그 휴식에 돌과 대화한다.

게임오버는 없다. 며칠 안 와도 돌이 죽지 않는다 — 대신 그 사이의 일이 이야기로 남는다.
호감도 같은 수치는 화면에 숫자로 뜨지 않는다. 돌이 어떤지는 관찰 문장으로만 알 수 있다.

## 기능

- **Flowtime 타이머** — 카운트업, 집중 길이에 따라 휴식 배정 (25분 미만 → 5분, 25–50 →
  10분, 50–90 → 20분, 90+ → 30분). 탭을 떠나면 멈춘다. 구간은 설정에서 바꿀 수 있다.
- **분위기 바** — 씬 아래 한 줄로 시간대·계절·날씨·소리를 고른다. 집중 중에도 만질 수 있다.
  - 날씨 9종: 맑음·흐림·안개·비·장대비 + 계절 전용(꽃잎비·풀잎비·낙엽비·눈)
  - 시간대 3종(한낮·해질녘·밤)과 계절 4종은 실시간 자동 또는 고정
- **소리풍경** — 상황(행동 × 보유 물건 × 날씨 × 계절)에 따라 13겹이 섞인다. 빗소리,
  발소리, 벽난로, 책장 넘기는 소리, 여름 매미… 두 가지 모드가 있다.
  - *지금 이 자리에서 들리는 대로* — 상황이 알아서 고른다
  - *모든 게 당신이 선택한 대로* — 겨울에 매미를 틀어 두고 싶다면
- **상점** — 물건을 사면 행동이 열리고, 씬에 배치되고, 소리가 한 겹 늘어난다. 소모품도 있다.
- **엔딩과 그 이후** — 1차가 끝나도 계속된다. 함께 살거나, 떠나보내거나. 그 뒤에도 이야기가 있다.
- **도감** — 지나간 순간과 뱃지. 못 본 것은 존재 자체가 보이지 않는다.
- **라이트/다크 테마**, 휴식 종료 알림.

저장은 브라우저(IndexedDB)에만 남는다. 계정도 서버도 없다. 내보내기·불러오기로 옮길 수 있다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm test          # 테스트
npm run validate  # 게임 데이터·문구 참조 검증
npm run build     # 프로덕션 빌드
```

### 소리 튜닝 페이지

`npm run dev` 후 <http://localhost:5173/tune.html>. 개발 전용이라 프로덕션 빌드에는
들어가지 않는다(빌드 입력은 `index.html` 하나뿐).

레이어의 대역·간격·게인을 슬라이더로 바꾸면서 **바로 듣는 화면**이다. 게임을 그 상황까지
진행하지 않아도 되고, 여러 레이어를 겹쳐 들으며 상대 음량을 맞출 수 있다(레벨 미터 포함).
찾은 값은 [코드 복사]로 [`src/audio/params.ts`](src/audio/params.ts)에 그대로 옮긴다.

소리는 코드가 아니라 데이터다:

| 파일 | 역할 |
| --- | --- |
| [`src/audio/params.ts`](src/audio/params.ts) | 레이어별 파라미터 + UI 스키마 |
| [`src/audio/models.ts`](src/audio/models.ts) | 데이터를 읽어 소리를 내는 엔진 (모델 7종) |
| [`src/audio/dsp.ts`](src/audio/dsp.ts) | 노이즈 소스, 듀티 펄스, 칩튠 양자화, 음계 스냅 |

튜닝 페이지와 게임이 같은 테이블·같은 엔진을 쓰므로 두 벌로 갈라지지 않는다.
