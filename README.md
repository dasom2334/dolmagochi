# 돌 다마고치 뽀모도로

집중용 Flowtime 타이머 + 돌 육성 웹게임. 서버 없는 리액트 SPA. 내가 쓰려고 만듬.

**▶ 플레이: https://dasom2334.github.io/dolmagochi/**

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 프로덕션 빌드
```

## 업데이트 예정

- 상점 확장 (아이템 티어·소모품, 행동 해금)
- 날씨·시간대 (비/눈, 밤/낮/동틀녘-해질녘 풍경과 소리)
- 행동별 ASMR 사운드
- 라이트/다크 테마
- 업적 뱃지 · 엔딩 이후 콘텐츠
- BGM (LP/mp3)
