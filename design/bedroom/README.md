## 무엇인가

거실(`design/livingroom`)에 이은 **두 번째 방**. 거실 v3처럼 시간·계절·날씨·돌·소품을
전부 토글하는 인스펙터가 붙어 있다. 아직 **앱 이식 전**(거실의 livingroom-port 같은
작업이 따로 필요) — 여기서 아트를 확정한 뒤 옮긴다.

## 아키텍처 — 거실 모듈 재사용

새 방을 위해 처음부터 만들지 않는다. 순수·공유 자산은 거실에서 그대로 import:

| 재사용 (거실 모듈) | 용도 |

| `livingroom/scene/lights.js` `VIGNETTE` | 가장자리 비네트 |

침실 고유:

| 파일 | 내용 |
|---|---|
| `geom-art.js` | **정적 아트** — 벽·바닥·창틀·가구를 레퍼런스에서 추출한 rect (자동 생성) |
| `tools/extract.py` | 추출 파이프라인 — `times/day.png` → 128×72 다운샘플 → 양자화(40색) → 셸 인페인팅 → 레이어별 rect |

## 아트 방식 — 손그림 폐기, 레퍼런스 추출 (2026-07-21 3차)

손으로 그린 가구가 레퍼런스 퀄리티에 못 미쳐, **리사이즈 허용을 받아** 거실과 같은
추출 방식으로 전면 재구축했다:

1. `times/day.png`(HD)를 **128×72 로 다운샘플** (앱 캔버스와 1:1)
2. 약한 웜 중화 후 **40색 양자화** → 깨끗한 도트
3. 가구 bbox 마다 **셸 인페인팅**(같은 행 clean 픽셀 복사)으로 배경을 메워 셸(벽·바닥)을
   만들고, 가구는 bbox 에서 셸과 다른 픽셀만 추출 → 레이어별 분리(게이팅 가능)
4. 창 유리 4판은 구멍 → **절차 하늘**(거실 모듈)이 시간대별로 비친다
5. 시간 오버레이는 베이스가 **낮 추출**이라 `OVL_GAIN`(낮 0.35)으로 약화, 노을·밤은 recolor

`tools/extract.py` 를 다시 돌리면 `geom-art.js` 가 갱신된다. **geom-art.js 손편집 금지.**

**거실과 결정적으로 다른 점**: 창이 **왼쪽**(x16~49)이다. 거실은 가운데였고,
`lights.js` 의 창광·오버레이 zone 이 그 전제로 잘려 있어 **창은 재사용 불가**였다.
그래서 창빛 웅덩이(`drawWindowPool`)와 방 영역 클립(`clipRoom`, evenodd)을 새로 잡았다.

## 렌더 순서

```
하늘(창 개구부 클립) → 벽 → 창틀 → 바닥 → 가구(z순서) → 돌
→ 시간·날씨 오버레이(방 영역) → 창빛 웅덩이 → 스탠드 발광 → 비네트
```

## 품질 개선 완료 (2026-07-21 2차)

레퍼런스를 128×72 로 내려(사용자 허용) 정밀 가이드로 삼고 전면 재작화:

- [x] **돌** — 손그림 폐기, **거실 생성 돌(ball/rim)** 재사용. 자리별 크기, 역광은 창빛색
- [x] **가구 투시·입체** — box() 투시 상판(소실점 x50 향해 물러남), leg() 명암면,
      침대 이불 주름·헤드보드, 협탁 서랍, 선풍기 가드링+날개살, 러그 투시 사다리꼴
- [x] **접지 그림자** — groundShadows() 를 렌더러가 multiply 로 바닥에 깐다
- [x] **벽 무늬** — 다마스크를 교점 1px 점으로 은은하게, 하단은 더 어둡게
- [x] **창빛 웅덩이** — 경계·멀리언 그림자 해시 디더로 부드럽게
- [x] **장면 레이어 토글** — 거실 v3 처럼 배경·창틀·벽·바닥·접지그림자·색감·창빛·비네트 on/off

## 남은 다듬기 (최종 검수 대상)

추출 재구축으로 벽·바닥·가구 퀄리티는 레퍼런스급이 됐다. 남은 것:

- [ ] **바닥 baked 햇빛 패치** — 추출 낮 베이스에 창빛 패치가 구워져 있어 밤에도 약간
      남는다(노을엔 오히려 자연스러움). 완전 동적으로 하려면 패치만 디라이팅 후
      동적 창빛으로 대체. 지금도 밤 오버레이가 눌러 크게 거슬리진 않는다
- [ ] **창밖 천체 위치** — 달·해가 거실 창 자리(x56)라 침실 유리 기준 살짝 치우친다
- [ ] **돌 의자 자리** — 좌판보다 살짝 높아 등받이와 붙어 보인다. y 미세조정
- [ ] **다른 시간대 세부 튜닝** — day/sunset/night 3장을 각각 추출해 셸을 시간별로
      바꾸면(furniture 는 공유) recolor 없이 더 정확해진다. 지금은 낮 1장 + 오버레이
- [ ] **앱 이식** — livingroom-port 같은 별도 작업(fromGame 침실 번역, 소품 게이팅,
      돌 자리 판정, 침실 렌더 컴포넌트)
