## 시안 3종

| 시안 | 파일 | 방식 |
|---|---|---|
| A | `geom-art.js` | **레퍼런스 추출** — `tools/extract.py` 산출물. 손편집 금지 |

| C | `geom-art-touch.js` | **추출 + 손보정** — A 를 바탕에 두고 안 읽히는 것만 B 에서 가져옴 |

시안 C 가 손으로 바꾼 것은 `KT_TOUCHED_IDS` 에 그대로 나온다(바닥·걸이도구·주전자·싱크대).
기준은 하나뿐이다 — **큰 면은 추출이 낫고, 작은 물건은 손이 낫다.**
바꾸는 것을 늘리면 B 와 구분이 사라지므로 함부로 늘리지 말 것.

## 세 시안이 공유하는 것

`geom.js` — 창밖 풍경·돌 3자리·창광·접지그림자·화구 발광·김.
시안이 달라도 **방의 구조(창 위치·바닥선)는 같으니** 광원과 그림자를 나눌 이유가 없다.
`render.js` 하나가 `state.variant`('a'/'b'/'c')로 정적 아트만 갈아 끼운다.

## 거실·침실과 다른 점

- **창이 오른쪽**(유리 x95~117, 중심 106). 거실은 가운데, 침실은 왼쪽이었다.
  → 창광이 아래로 갈수록 **왼쪽으로** 흐르고(skew 음수), 접지 그림자도 왼쪽으로 눕고,
  돌의 역광은 `rimSide` 가 창 쪽 모서리를 잡는다.
- 바닥선 `FLOOR_Y = 51` (거실·침실은 49).
- 방 안 광원이 **스탠드가 아니라 화구**다 — 주전자를 끄면 같이 꺼진다.

## 추출 파이프라인에서 배운 것 (tools/extract.py)

1. **전역 양자화가 소수색을 먹는다** (§6.2 그대로). 36색 전역 medianCut 을 걸었더니
   빨간 법랑 주전자가 통째로 나무 갈색에 흡수됐다 — 씬의 유일한 색 앵커가 사라진다.
   → **리전별 양자화**(배경 22색 + 소품 박스마다 12색)로 해결.
2. **웜캐스트 중화·채도 부스트에도 예외가 필요하다.** 주전자는 원본이 2톤뿐이라
   채도 ×1.42 를 걸면 둘 다 상한에 붙어 한 색으로 뭉개진다(형태 소실).
   → `CHROMA_KEEP` 박스만 중화 0.40·채도 ×1.05.
3. **창(발광)은 플랫필드 계산에서 빼야 한다.** 안 빼면 밝은 창이 주변 벽을 과하게 누른다.
4. **디셰이드는 벽 전체에 걸면 안 된다.** 반경 안에 든 소품까지 지역 평균으로 끌려가
   색이 빠진다. 바닥(광 웅덩이)에만 건다.

## 손작화에서 배운 것 (geom-art-hand.js)

- **바닥 세로 줄눈은 소실점(x66.5)으로 모여야 한다.** 격자를 그대로 깔았더니
  바닥이 아니라 정면 벽돌담으로 읽혔다. 눈높이 y22.4 기준으로 투영하고,
  깊이 선 간격도 앞으로 갈수록 벌린다.
- **바닥은 벽보다 어둡게.** 밝으면 앞으로 튀어나와 방이 얕아 보인다.
