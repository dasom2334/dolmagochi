## 3. 검증 완료 (확정 사항)

### 3.1 에셋 아키텍처 — 3계층 합성
```
기본 방(중립) + 소품(중립)
→ 시간 색감 오버레이 (낮/노을/밤, multiply)
→ 날씨 색감 오버레이 (맑음=없음/흐림/비/눈, multiply)
→ 광원 (개별 SVG 5종, 각자 Light Mask)
→ emission (발광체, 최상단)
```
- 오버레이 2장 중첩 = 계산된 최종 오버레이 1장과 수학적으로 등가 (multiply 결합법칙). 제작은 분리 관리, 렌더링은 중첩으로 OK.
- 48조합(3×4×4)이 12장 배경이 아니라 레이어 합으로 표현됨을 실증.

### 3.2 소품 4레이어 (에셋 제작 단위)
| 레이어 | 블렌드 | 대상 | 내용 |
|---|---|---|---|
| base | normal | 전부 | 중립 색·입체감·AO만 |
| shadow | multiply 12~40% | 전부 | 접지 그림자·틈새 (시간 불변) |
| emission | 최상단 배치 | 발광체만 | 불꽃·촛불 화염·스탠드 전구 — 밤에도 안 어두워짐 |
| lightmask | 화면 비표시 | 렌더러 지원 시 | 오클루더(빛 차단 실루엣) |

- **highlight 레이어는 비채택** — 시간별 광원 방향이 바뀌므로 구우면 어색해짐.
- SVG는 네이티브 `<mask>`가 있어 lightmask 사용 가능. PNG+CSS로 갈 땐 base+shadow+emission 3레이어로 강등.

### 3.3 물리 광원 규칙
- **태양/달 = 원거리 평행광**: 창을 통과한 빛은 원뿔이 아니라 **창 크기 그대로의 패치**. 고도에 따라 길이·스큐 변화(낮=짧고 가파름, 노을·밤=길고 왼쪽 스큐 — 태양이 창 중심 오른쪽). **수평면(창턱 상단·바닥)에만** 투영, 창 밑 벽은 그림자.
- **벽난로 = 점광원**: 역제곱 감쇠 3단 링(바닥+벽). 촛불=소반경, 스탠드=전기등(플리커 없음).
- **광원 = 셰이프(고정) × 색·세기 테이블**: `--wl/--wl-a` 등 CSS 변수. 캐스케이드: 시간이 기본값 → 날씨가 나중에 오버라이드 → 계절은 컴파운드 예외(겨울 낮=차가운 흰 빛).
- **그림자 = Light Mask + 오클루더**: 광원마다 mask(m-day/m-low/m-fire), 소품별 오클루더(.occ-orb 등)가 소품 토글과 연동(끄면 그림자도 사라지고 빛 통과). 마스크 그레이 레벨 = 반그림자.
- 벽난로 불빛의 그림자(상자)는 광원 그룹 소속 → 불빛 끄면 그림자도 꺼짐(물리적으로 올바름).

### 3.4 z-순서 (뒤 → 앞)
```
[1] 방 구조   벽 → 바닥 → 창틀·창턱 → 벽난로 → 책장  (+각자 p-shadow)
[2] 창밖      하늘 → 해 → 달 → 별 → 구름 → 나무 → 비·눈·계절 파티클 → 유리 효과
[3] 소품      책장 책 → 촛대 → 창턱 화분 → 돌멩이 → 러그 → 스탠드 → 바닥 소품
              (선반 안 → 맨틀 → 창턱 → 바닥 깔개 → 바닥 스탠딩 순. 러그는 깔개라 바닥 소품보다 뒤)
[3.5] 창틀 눈쌓임 (날씨 틴트 받도록 오버레이 앞)
[4] 색감 오버레이  시간 → 날씨
[5] 광원(mask)    창문 햇빛 → 달빛 → 벽난로 → 촛불 → 스탠드
[6] emission      불꽃 → 촛불 화염 → 스탠드 전구
```

### 3.5 축별 책임
- **시간**: 하늘 팔레트(k0~k6) + 해↔달·별 + 광원 색/세기 + (예외) 밤 언덕 실루엣
- **계절**: 창밖 나무(t0~t2 잎, 겨울=잎 숨김+앙상한 가지) + 언덕(h0~h3) + 계절 파티클(봄 꽃잎/가을 낙엽/여름밤 반딧불) + 성에(겨울)
- **날씨**: 구름(흐림·비·눈 공용) + 파티클(비/눈) + 광원 감쇠 + 해·달·별 숨김 + 창문 효과(빗방울 유리/창틀 눈쌓임)
- 컴파운드 예외 3개: 밤+겨울 언덕(달빛 눈), 노을+겨울 언덕(눈빛 유지), 낮+겨울 창문 빛(찬 흰색)

### 3.6 풀캔버스 배경
창은 벽의 구멍일 뿐 — 풍경은 캔버스 전체에 존재(클립 없음). 창 밖 영역은 행별 최빈 클러스터로 확장(하늘 밴드→언덕→지면), `var()` 참조라 테마 연동. 파티클도 벽에 가려지는 물리 구조.

## 4. 배운 것 (레슨 로그)

1. **레퍼런스 재현은 감이 아니라 추출**: 셀 크기는 행/열 차분 자기상관으로 측정(15.08px), 색은 리전별 k-means, 그림은 다운샘플 그리드를 run-merge된 rect로 방출(~1,800개).
2. **전역 k-means는 소수 색을 흡수한다** — 돌 회색(~120셀)이 핑크 클러스터에 먹혔음. 리전별 팔레트가 필수.
3. **디라이팅**: 채널별 나눗셈은 색이 보색으로 뒤집힘(올리브화) → **휘도만** 플랫필드하고 전역 웜캐스트는 60%만 중화. 단, 블러 반경보다 큰 광 웅덩이는 못 지움 → §4.4로 해결.
4. **텍스처 전사**: 질감(고주파) = 휘도÷블러(비율, 0.70~1.38 클램프), 조명(저주파) = 블러에 흡수돼 버려짐. 중립 톤 × 비율로 재조합. **크로마는 전사 금지** — 잔광의 색조가 따라온다.
5. **발광체(불꽃·해·촛불)는 디라이팅 제외** — 알베도가 아니라 광원이므로 원본색 유지. 디라이팅하면 황록색으로 변색.
6. 디라이팅+양자화는 대비를 누른다 → 팔레트 `punch()`(명도 S커브 ×1.22, 채도 ×1.2, 발광체 제외)로 복원.
7. **배경 분리는 셀 좌표 규칙으로** (gen.py `static_sub`). 렌더된 rect를 bbox로 사후 분류하면 색 런 경계 때문에 오분류.
8. **mix-blend-mode를 그룹에 걸면 안 됨** — 자식의 multiply 그림자가 무력화. 블렌드는 자식별, 그룹은 opacity만.
9. CSS 규칙: 컴파운드는 input DOM 순서 의존(`#t-X:checked ~ #s-Y:checked ~ .scene` — 시간→계절→날씨 순 배치). 마스터 토글은 `!important`로 조건부 show를 이김. 패널 활성 표시는 `#input:checked ~ .panel label[for=...]`.
10. **mask 내부 요소도 CSS display 토글이 먹힌다** → 오클루더-소품 연동의 핵심.
11. 스프라이트 뒤 배경은 인페인팅(같은 행 최근접 비스프라이트 셀 복사) — 토글 off 시 구멍 방지.
12. 애니메이션: `steps()`로 픽셀 낙하감, 파티클은 타일+`<use y=-30>`+translateY(30px) 루프, 불꽃은 `transform-box:fill-box`+origin bottom, `prefers-reduced-motion`에서 일괄 정지.
13. **Claude 브라우저 패널 퀴크**: file:// 리로드 시 폼 상태를 DOM 위치 기반으로 복원해 토글이 뒤섞여 보임 → 검증은 javascript_tool로 상태 명시 후 스크린샷. 탭이 URL에 고정되기도 함(force navigate가 새 탭 생성).
14. 전환 직후 스크린샷은 transition(.6s) 중간이 찍힘 — 1초 대기 후 캡처.

## 6. 생성 원칙 (본게임 에셋 제작 규칙)

1. **모든 에셋은 무광원 중립(albedo) + AO만** — 시간·날씨·광원 색을 절대 굽지 않는다. AO 허용 범위: 접지 그림자, 선반 안쪽, 틈새, 물체끼리 맞닿는 곳.
2. 시간·날씨 색감은 **오버레이 2장(multiply)** 으로.
3. 광원은 **셰이프 1장 + 상태별 색·세기 테이블**. 시간→기본, 날씨→오버라이드, 계절→컴파운드 예외.
4. 발광체만 **emission 분리**, 항상 최상단.
5. 그림자는 **오클루더**(빛 차단 실루엣, 단순 다각형)로 — 소품 on/off와 연동.
6. §3.4 z-순서 준수.
7. 도트: 96×72 그리드 기준, `shape-rendering: crispEdges`, 디테일(나뭇결·문양·노이즈)은 레퍼런스 텍스처 전사로.
8. PixelLab 프롬프트 시: "unlit, neutral albedo, ambient occlusion only, no directional light, no color cast" 계열로.
